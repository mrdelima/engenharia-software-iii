# Sistema de Controle de Estoque (SGE)

## Engenharia de Software III — Documentação e Modelagem UML

### Sobre o Projeto

Este repositório contém a documentação de especificação e modelagem UML de um **Sistema de Controle de Estoque (SGE)**, desenvolvido como atividade acadêmica da disciplina de Engenharia de Software III.

O projeto tem como objetivo modelar um sistema para gerenciamento de materiais e insumos de uma organização, contemplando o controle de entradas e saídas, cadastro de produtos, gerenciamento de fornecedores e monitoramento automático dos níveis de estoque.

### Funcionalidades Especificadas

O sistema contempla as seguintes funcionalidades:

- Cadastro, consulta, alteração e inativação de usuários.
- Gerenciamento de produtos com identificação por código de barras.
- Categorização de produtos.
- Cadastro e gerenciamento de fornecedores.
- Registro de entradas de produtos vinculadas a notas fiscais.
- Registro de saídas com identificação do funcionário responsável e setor de destino.
- Controle de estoque mínimo.
- Emissão de alertas automáticos de estoque baixo.

### Modelagem UML

A documentação apresenta os seguintes artefatos de modelagem:

| Artefato | Descrição |
|---|---|
| Requisitos funcionais | Definição das funcionalidades do sistema. |
| Requisitos não funcionais | Definição dos critérios de qualidade e desempenho. |
| Diagrama de Casos de Uso | Representação das interações entre atores e sistema. |
| Documentação de Casos de Uso | Descrição dos fluxos principais e alternativos. |
| Diagrama de Classes | Estrutura das classes, atributos, métodos e relacionamentos. |
| Diagramas de Sequência | Representação das interações para registro de entradas e saídas. |

Os diagramas foram documentados utilizando a linguagem **PlantUML**.
